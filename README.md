# SIMRS Intelligent — POC Prototype

Prototype UI **SIMRS** untuk **PT. Rizia Mitra Sejati**.

> **POC / simulasi** — bukan koneksi live VClaim, Antrol, Applicare, SatuSehat, atau PSC ambulans.

## Preview

- File utama: [`design/mockup.html`](design/mockup.html)
- Buka lokal: `python -m http.server 8080` di folder `design/`, lalu `http://localhost:8080/mockup.html`
- Deploy Vercel: root project ini; `/` diarahkan ke mockup (`vercel.json`)

## Modul (mockup)

Dashboard · Pendaftaran · Antrian Poli · Pelayanan Poli · Rawat Inap · Farmasi · Kasir · Rekam Medis · Jadwal Dokter · Master Data · IGD (+ ambulans simulasi) · Bridging BPJS (simulasi)
